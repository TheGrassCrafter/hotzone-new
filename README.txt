HOTZONE – Neustart

Dateistruktur:
index.html
netlify.toml
package.json
netlify/functions/hotzone.mjs

Neu veröffentlichen:
1. Entpacke diese ZIP.
2. Erstelle auf GitHub ein neues Repository namens hotzone-neu.
3. Lade die Dateien so hoch, dass index.html und netlify.toml direkt im Hauptordner liegen und hotzone.mjs in netlify/functions/.
4. Öffne Netlify → Add new project → Import an existing project → GitHub und wähle hotzone-neu.
5. Lasse den Build-Befehl leer. Die netlify.toml enthält die Einstellungen.
6. Starte Deploy und warte auf einen erfolgreichen Production-Deploy.
7. Teste die neue Website. Öffne sie zusätzlich in einem zweiten Browser oder auf einem zweiten Gerät und tritt mit dem Code bei.

Der Code ist fünf Minuten nach dem Erstellen für neue Beitritte gültig. Freunde müssen ihn innerhalb dieser Zeit eingeben. Bereits beigetretene Spieler können nach Ablauf weiterspielen; weitere Spieler können dann nur mit einem neuen Raumcode beitreten. Es werden keine echten Namen oder Konten benötigt.
